## 旧料金ID の既存契約（2026-10-13）

現在の16コースに無い料金ID の契約は、旧プランの仕様を確かめたものだけを対応表（環境変数 `STRIPE_LEGACY_PLANS_JSON`。形は `lib/billing/prices.ts`）に入れて扱う。
金額だけで対応先を決めない（根拠 source が無い行は使わない）。旧プランは新しい申し込みには出さず、Webhook と契約画面（「○○（既存契約）」）だけで使う。料金の変更・契約の移行・解約はしない。
対応の分からない料金ID の通知は、有料の権限を付けず、いまの権限も変えずに「確認待ち」（0018 の review_* 列）として記録し、管理者の料金画面に理由と「契約を再確認」を出す。
確認待ちの間は新しい申し込みを受け付けない（二重の契約を防ぐ）。調べ方：`npm run billing:audit`（読み取りだけ）・`supabase/runbook/billing-audit.sql`。
2026-10-13 時点：リポジトリの履歴に旧料金ID は無い（現在の16個だけ）。Stripe・DB は開発環境から接続できず未確認。

数え方（以前からの仕様。変えていない）：1回＝生徒1人分の答案（2ページ・20問まで、PDF は不可）の採点1回。再採点も1回。通信の再送・3モデル併用の追加の点検では増えない。失敗した採点は数えない。
学校の「枚」も同じ数え方（画像のページ数ではない）。期間：有料は Stripe の契約期間ごと、無料（月20回）は日本時間の暦月。

## 実装範囲

契約・Stripe決済・採点回数の上限・Opus単独55円の支払い確認・夜間予約処理を追加した。設定・有効化・検証は docs/BILLING-NIGHT.md を参照。既存契約・既存答案を移行だけで変更しない。設定前は申し込みと夜間受付を停止して「提供準備中」を表示する。

契約期間ごとに採点1回で1枠（再採点も1回）、失敗時は枠戻し。通信再送・追加モデル点検は増枠しない。Opus55円は採点ごとの支払いで、確認後にサーバーが実行。失敗時は返金処理。通常・夜間の方式は契約から判断し、ブラウザの指定だけで夜間を即時実行しない。

ChatGPTの契約・利用料は生徒本人または保護者の負担で、アプリ料金に含まない。本番へのSQL適用・マージ・公開・実課金は行っていない。

## 学校プランの月間枚数（2026-10-09）

ユーザーの依頼により、学校ミニ800枚・ライト2,500枚・スタンダード4,500枚・学校プロ6,500枚を表示用カタログに設定。採点方式の既定がOpus単独のため、その原価でも利益を残す基準にした。

試算は1枚＝生徒1人分（2ページ・20問）、1USD=150円、再採点予備10%、保存・通信等0.6円、模範解答取込配賦0.5円。Opus単独の変動費は約26.43円/答案。決済手数料は税込入金額の3.6%、学校別対応費は3,000円/月の仮定。通常価格では共通固定費控除前の利益率が約35%以上になる。実測原価ではないので採算は保証しない。

課金経路の採点は2ページ・20問までに制限。大きい答案の料金は別途確定する。

## 個人・塾プランの採算基準

Haiku全件、Sonnet追加確認20%、Opus追加確認5%の仮定で変動費約6.49円/答案。割合は実測・上限ではなく、実際の確認理由で上位モデルへ進む。税込入金額の決済費3.6%、契約別対応費200円/月、全員が上限利用の条件で、共通固定費控除前の利益率は約35〜40%。Opus単独は同条件で変動費約26.43円/答案。実測原価による採算保証ではない。

採点方式の新しい既定は3モデル併用。保存済みの端末設定は保持する。個人・塾でOpus単独を選ぶ場合は追加料金を確認する。
