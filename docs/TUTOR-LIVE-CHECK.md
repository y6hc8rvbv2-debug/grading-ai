# チャッピー先生：本物の OpenAI で確かめる手順（本人のキーを安全に使う）

自動テストは OpenAI の代役で行っている。本物の OpenAI Realtime で動くか（通話の作成・イベント名・切断・料金）は、
**キーの持ち主（検証用に契約した人）が自分の PC で**、次の手順で確かめる。

> **有料の確認（手順 C・D）は、依頼者が「実行してよい」と指示するまで行わない。**
> 手順 B は無料（`GET /v1/models` だけ）。管理者・学校のキーは使わない。

---

## A. 準備（OpenAI の管理画面で。アプリの外）

1. 検証専用の **Project** を作る（例：`chappy-live-check`）。普段使いのプロジェクトのキーは使わない
2. その Project に**予算の上限**（例：月 $5）と通知を設定する
3. その Project で **API キーを1つ作る**。権限を絞れる場合は、Realtime と Models の読み取りだけにする
4. キーはパスワード管理ソフトに保存し、チャット・メール・メモ・スクリーンショット・このリポジトリには書かない

## B. 無料の確認（キーとモデルの一覧）

```bash
npm ci
npm run tutor:live-check
```

- 「OpenAI API キー」と聞かれたら貼り付けて Enter（**入力した文字は表示されない**）。パスワード管理ソフトのコマンドから渡すこともできる（例：`op read ... | npm run tutor:live-check`）
- 結果：キーが有効か、**音声会話に使えるモデル**（アプリの設定画面に出るものと同じ）、字幕に使う文字起こしのモデル
- キーはファイル・環境変数・ログに書かない。`OPENAI_API_KEY` などの環境変数のキーは読まない（アプリと同じ `lib/tutor/openai.ts` を使う）

## C. 有料の確認（通話を1回・文字で1往復・サーバー側から切る）　※指示があるまで実行しない

```bash
npx playwright install chromium   # 初回だけ（Chromium で本物の WebRTC の申し込みを作る）
npm run tutor:live-check -- --paid
```

- キーを入れたあと「有料で実行します」と**そのまま入力したときだけ**実行する。それ以外は何もせず終わる
- 行うこと：本物の WebRTC の申し込み → アプリと同じ関数で `POST /v1/realtime/calls` → データチャネルで「1+1は？」を送る →
  受け取ったイベント名をアプリが使う名前と照合 → `POST /v1/realtime/calls/{id}/hangup` で切る → ブラウザ側の接続が閉じたかを確認
- マイク・音声は使わない（文字だけ。料金を小さくするため）。最大60秒。モデルは gpt-realtime-mini があればそれを使う
- 結果の見方：すべて ✓ なら、接続方法・イベント名・サーバーからの切断が本物でも動く。✗ があれば、表示された内容を開発担当に渡す（キーは渡さない）
- 料金は OpenAI の管理画面の Usage で確かめる

## D. アプリ（Vercel の Preview）での確認　※指示があるまで実行しない

1. Preview に 0012 まで適用した Supabase を使う（本番 DB は使わない。`docs/DB-RUNBOOK.md`）
2. 検証用の生徒アカウント（実在の生徒ではない）を作り、配信先に登録する。先生アカウントで練習用の答案を確認・返却する
3. 生徒アカウントで `/student` → 受信箱 → 間違えた問題 → 設定で同意 → 手順 A のキーを登録（「保存しない」を推奨）
4. 「文字で質問する」→ 1往復 →「会話を終える」。次に「音声で質問する」（実機の手順は `docs/TUTOR-DEVICE-CHECK.md`）
5. 終了の確認：管理者が学校の設定で無効にする → **20秒以内に会話が止まる**こと、同意の撤回で止まること、1回の上限（設定画面で最小に）で止まること
6. OpenAI の Usage に記録された料金と、アプリの「使用量」の表示を比べる

## E. 後片付け

1. OpenAI の管理画面で、手順 A のキーを**無効にする（削除）**
2. アプリに保存した場合は、生徒の設定画面の「保存したキーを削除」
3. 予算を使い切るまで Project を残すか、不要なら Project ごと閉じる
4. 端末のシェル履歴にキーが残っていないか確かめる（貼り付けは入力欄にだけ行い、コマンドには書かない）
