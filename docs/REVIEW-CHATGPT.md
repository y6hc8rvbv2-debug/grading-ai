# 生徒の復習：本人の ChatGPT で復習（B方式）導入ガイド

**いまの方針は、この B方式だけを使う**（2026-10-07 決定）。アプリ内の AI との音声・文字の会話（A方式「チャッピー先生」。`docs/VOICE-TUTOR.md`）は、
画面に出さず、サーバーでも断る（環境変数 `TUTOR_INAPP=on` のときだけ動く。既定は無効）。

先生が確認して本人に返却した答案から、生徒が間違えた問題を選び、「送る内容」を確かめてからコピーし、
**自分の ChatGPT にログインして貼り付け、自分で音声会話を始めて**復習する。

---

## 1. しくみ（アプリがすること・しないこと）

| アプリがすること | アプリがしないこと |
|---|---|
| 本人に返却された答案の、間違えた問題を一覧にする | AI を呼ぶ（採点AI・OpenAI とも呼ばない） |
| 1問分の「送る内容」を画面に出し、生徒が確認のチェックを付けたらコピーできるようにする | 生徒の代わりに ChatGPT へログイン・貼り付け・送信・音声の開始をする |
| 「ChatGPT を開く」で `https://chatgpt.com/` を新しいタブで開く | 会話の開始・会話の内容・理解度を受け取る、または受け取ったように表示する |
| 復習の状態を**生徒の自己申告**として記録する（復習中／理解できた／先生に質問したい） | 生徒の自己申告を「理解確認済み」にする（これは先生だけ） |

- コピー内容は**ブラウザの中だけ**で作る（`lib/tutor/review-copy.ts`）。アプリのサーバー（`/api`）にも送らない
- そのため、**暗号鍵（`TUTOR_KEY_ENCRYPTION_KEY`）・`CRON_SECRET`・見回り（pg_cron）・OpenAI の API キーは不要**。Supabase の DB だけで動く
- 復習しても、テストの点数・赤ペン・先生のコメント・成績は変わらない

## 2. コピーする内容

| 入れるもの | 条件 |
|---|---|
| 家庭教師への指示（最初は答えを言わず、どこで迷ったかを聞く → ヒントを1つずつ → 手順を1段ずつ → 練習問題で確認・まとめ） | いつも |
| 学年・教科・問題番号（例：大問1-(2)） | いつも |
| 問題文 | 先生がテストの設定で入力した場合（無ければ「生徒に尋ねて」と書く） |
| 本人の解答（AI の読み取り結果）・判定と得点・先生のコメント | いつも |
| 正答・解説 | **先生がテストの設定で「返却時に、正答・解説を生徒に見せる」にしたときだけ**（返却した時点の設定。DB の返却内容にもそれ以外は入らない） |

**入れないもの**：氏名（DB に持っていない）・学校名・クラス名・出席番号・受験番号・匿名ID・テスト名・答案画像・メールアドレス。
先生のコメントに名前などを書いた場合はそのまま入るので、**コメントに個人情報を書かない**。生徒の画面にも「名前が書かれていたら、貼り付けたあと送る前に消す」と出している。

資料の中の文（答案・コメント）は「資料」として渡し、指示として従わないよう ChatGPT に伝えている（完全な防止ではない）。

## 3. 設定（先生・管理者）

1. 管理者が Supabase で `supabase/migrations/0015_review_copy.sql` を実行する（0012〜0014 の後）。設定画面の「AI採点の準備状況」に「ChatGPT で復習の設定（0015）」が「済」と出る
2. 設定画面 →「生徒の復習：本人の ChatGPT で復習」で、**学校で有効にする**と**使えるクラス**にチェックして保存（先生・管理者が変更できる。監査ログに残る）
   - **既定は無効**。学校とクラスの両方が有効なときだけ、生徒の画面に「ChatGPT で復習」が出る
   - アプリ内の会話の設定（`schools.tutor_enabled`・`classes.tutor_enabled`）とは**別の設定**。B方式を有効にしても、アプリ内の会話は有効にならない。
     逆に、以前にアプリ内の会話を無効にしていても、B方式は止まらない（別に切り替える）
3. テスト管理 → テストの「生徒の復習（ChatGPT で復習）用の設定」で、必要なら問題文を入力し、正答・解説を見せるかを選ぶ（次の返却・返し直しから反映）
4. 有効にする前に、ChatGPT の利用条件（年齢・保護者の同意など）を確かめる（開発側では未確認。規約ページに届かないため）

## 4. 生徒の操作（画面に短く出している手順）

1. `/student` にログイン → 受信箱 → 返却された答案 →「間違えた問題」の「ChatGPT で復習」
2. 「送る内容」を読んで確かめ、「送る内容を確認しました」にチェック
3. 「復習内容をコピー」（コピーできない端末では、文章を長押し →「すべて選択」→「コピー」）
4. 「ChatGPT を開く」→ 自分のアカウントでログイン → 貼り付けて送る
5. 声で話したいときは、ChatGPT の音声モードを自分で始める
6. 終わったら、必要なら「理解できた（自己申告）」などを押す（先生には自己申告として見える）

## 5. 先生が見られるもの

答案詳細 →「設問別採点」→「生徒への返却と復習」：返却の版と、間違えた問題ごとの復習の状態（生徒の自己申告／先生の確認）。
「理解確認済みにする」は先生だけ。取り消すと「未記録」に戻る（生徒の自己申告に見せかけない）。ChatGPT での会話の内容・回数・時間はアプリに届かない。

## 6. 検証済みのこと（開発環境）

- `npm run test:unit`：コピー内容（入れるもの・入れないもの・未公開の正答の除外）、A方式は既定で無効、B方式の画面が AI・キー・暗号鍵・見回りのコードに依存せず `/api` も呼ばないこと（`tests/unit/review-copy.test.ts`）
- `npm run test:db`：0015 の既定は無効・生徒は設定を変えられない・学校とクラスの両方が必要・A方式の設定は変わらない・他の生徒の返却内容/受信箱/復習の状態は読めない・自己申告は「確認済み」にできず先生の確認を上書きできない（`supabase/tests/review_copy_test.sql`）
- `npm run test:e2e:lite`（Docker 不要。専用の PostgreSQL＋全マイグレーション＋本物の PostgREST＋ログイン・画像だけの代役）：
  スマホ幅（390px）で、既定は非表示 → 先生が設定画面で有効化 → 確認前はコピー不可 → コピー内容＝画面の内容 → 「ChatGPT を開く」が新しいタブで公式 URL を開く →
  未公開の正答・学校名・番号・テスト名・画像のパスが入らない → 公開したテストでは正答・解説が入る → 他の生徒の返却内容は REST で読めない →
  採点AI・OpenAI の宛先（罠のサーバー）に要求が0件・ブラウザはアプリと DB 以外に要求しない → アプリ内の会話・キー登録の API はサーバーが断る（`inapp_off`）。
  アプリは暗号鍵・`CRON_SECRET`・service_role・API キーを渡さずに起動（`tests/e2e-lite/`）

**未確認**：本物の Supabase（クラウド）・Vercel の Preview での動作、iPhone/iPad の Safari・Android の Chrome の実機でのコピーと ChatGPT アプリへの受け渡し、ChatGPT の利用条件（年齢・保護者の同意）。
