# 「テストを追加」の下書きを、別の URL・端末へ移す

下書き（資料の画像・設問・確認の印）は、ブラウザの中に URL ごとに保存されます。
Vercel の Preview は版ごとに URL が変わることがあり、別の URL では前の下書きが見えません。
次のどれかで移せます。どれも **AI は呼びません**（料金はかかりません）。

## A. 新しい版どうし：「下書きを書き出す／読み込む」

1. 下書きがある画面で「テスト管理」→「＋ テストを追加」→ 上の「下書きを書き出す（ファイル）」を押す
2. 移したい画面で「＋ テストを追加」→「下書きを読み込む（ファイル）」でそのファイルを選ぶ

## B. 書き出しボタンが無い以前の版から（例: grading-38gtz73zq-….vercel.app）

1. **下書きを作ったときと同じブラウザ**で、以前の URL を開いてログインする（「テストを追加」は開かなくてよい）
2. 開発者ツールを開く（Windows: `F12`、Mac: `⌥⌘I`）→「Console（コンソール）」タブ
   - Chrome で貼り付けが止められたら、案内どおり `allow pasting` と入力して Enter
3. [`docs/draft-export-snippet.js`](./draft-export-snippet.js) の中身を全部貼り付けて Enter
   → `test-draft.json` がダウンロードされ、「資料 ○ 件・設問 ○ 問」と表示される
4. 新しい Preview で「＋ テストを追加」→「下書きを読み込む（ファイル）」で `test-draft.json` を選ぶ

## C. 予備：サーバーに残っている AI の読み取り結果から再開

端末の下書きが取り出せないときは、「＋ テストを追加」→「以前のAI読み取り結果から再開」→「この結果で再開」。
まだテストに登録していない、自分の読み取り結果（資料と設問）を戻します。
**読み取りの後に手で直した配点・正答・確認済みの印は含まれない**ので、もう一度確認してください。

## 注意

- 書き出したファイルには資料の画像がそのまま入ります。生徒の答案を資料にした場合は氏名が写っていることがあるので、
  読み込んだ後はファイルを削除し、メールなどで送らないでください。
