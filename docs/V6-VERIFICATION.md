# テスト採点ver6　検証の記録（2026-10-19）

開発側（Claude）が行った検証と、その結果です。本物の AI・本物の決済には接続せず、**代役（モック）**を使っています。
代役は、アプリが送る要求の形（モデル・設定・画像・プロンプトキャッシュなど）を検査し、形が違えば失敗にします。

ver6 の画面テスト（`tests/e2e-lite/ver6.mjs`）で確かめたこと：

- **おまかせ採点**：答案3枚を入れるだけで、受験番号からクラス・生徒、印刷されたテスト名からテストを自動で選び、確認のチェックを自動で付け、5秒後に自動で採点を開始。3枚を同時に採点し、全員満点で保存
- **100枚以上**：120人分を一度に取り込み、全員を自動で振り分け・採点。1件1.5秒の代役で **44秒**（順番に採点すると180秒以上）
- **生徒のスマホから提出**：QR のリンク → 出席番号 → 撮影 → 提出 → 先生の画面に届き、そのまま採点。先生が取り込んだ答案は上書きされない。でたらめなリンクは拒否。締め切りできる
- **模範解答の作成**：下書き（Sonnet 5.5）と独立検算（Opus 5.5）。20問中18問が「検算一致」で個別確認を省略。食い違いは要確認＋判定に回す
- **AIエンジン**：新しいモデル（代役の Claude Sonnet 6）を案内し、ワンタップで切り替え・既定に戻す。一覧に無いモデルは保存できない
- **言語**：🌐 はヘッダーのいちばん右。英語・アラビア語（右から左）に切り替わる
- **便利機能**：Ctrl+K で移動・統計と校務用CSV（未提出つき）・同じ解答のまとめ判定・キー操作・テストの複製・コメントの定型文・今月のAI採点
- **前払い**（料金の画面テスト）：金額はサーバーが料金表から決める・通知の前は有料にしない・再送で二重に延ばさない・月額との重複を断る

主な画面の写真：`docs/screenshots/ver6/`（このテストの途中で撮影）

## 検証中に見つけて直した不具合

- 採点中の画面で、最初の答案が届くと画面の形が変わり、生徒の提出パネル（作ったリンク）が消えていた
- 複製した「〇〇（コピー）」があると、答案のテスト名からテストを選べなかった（完全に同じ名前を優先するようにした）
- ver5 の自動振り分けは、一度失敗した写真を二度と読み取れなかった（やり直せるようにした）

## まだ確かめられていないこと（先生の確認・本番でしか分からないもの）

1. **本物の Claude での採点の精度・時間・費用**（開発環境に API キーが無いため。ver5 から同じ）
2. **本物のスマホ（iPhone Safari・Android Chrome）**での撮影と提出
3. **本物の Stripe**（テストモード）でのコンビニ払い・PayPay の入金の知らせ、**本物の暗号資産の決済代行**の通知
4. **Vercel（HTTP/2）での同時採点の数**：手元のテストは HTTP/1.1 のため、ブラウザの上限で同時6件まで（設定は8件）。本番の HTTP/2 では上限が無く、設定どおりの見込み
5. **Anthropic の利用上限（レート制限）**：同時に多く送ると、混み合いの応答（429）が出ることがある。アプリは自動で待ってからやり直す（単体テストで確認）が、上限の値はアカウントの契約で変わる
6. Docker を使う通しテスト（`npm run test:e2e`）は、この環境で Docker が使えないため未実行（代役の更新は行った）
