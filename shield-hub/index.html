本番で使う前に、Vercel の「Settings → Environment Variables」で HUB_SECRET（16文字以上のランダムな文字列）を登録し、再デプロイしてください。 登録しないと、誰でもリズムを予測できてしまい、探知の意味がなくなります。

しくみ（かんたん説明）

画面を盗み見て外へ送る「のぞき見ソフト」は、画面が変わった瞬間に通信量が増えるというクセがあります。これを利用します。

  1. 司令塔が、他人には予測できない「秘密のリズム」（画面を変える時刻の一覧）を作ります。
  2. 画面の一部（時計など）を、そのリズムどおりに少しだけ変化させます。
  3. パソコンの通信を宛先ごとに0.1秒刻みで数えます。
  4. リズムとそっくりに増減する宛先＝画面のこだまを返している宛先です。のぞき見の疑いがあります。
  5. 許可した共有先（会議ツールなど）でなければ「遮断」と判定し、署名つきの指示を出します。

相関の強さ（0〜1）が 0.3以上 で「こだまあり」と判定します。

体験してみる（シミュレーション）

本物の通信は使いません。画面の時計をリズムどおりに変化させ、3つの宛先の通信量を作って判定します。

判定の結果

本物の通信で試す

  1. 下の「リズムを受け取る」を押すと、時計がリズムどおりに変化し始めます。
  2. そのあいだ、自分のパソコンで Wireshark で通信を記録します。
  3. Wireshark の「ファイル → エクスポート → CSV」で、Time（時刻）・Destination（宛先）・Length（バイト数）を含むCSVを書き出します。
    時刻は「表示 → 時刻表示形式 → UTC日時」または「エポック秒」にしてください。
  4. CSVを読み込んで「判定する」を押します。
🔒 宛先のIPアドレスはサーバーへ送りません。この画面の中で「宛先1」「宛先2」…に置き換えてから送ります。対応表はこの画面にだけ表示され、どこにも保存されません。
自分のパソコン・自分が管理する機器の通信だけで試してください。

API（いま使えるもの）

  • GET /api/hub-rhythm?sid=…&dur=秒数 … 秘密のリズムを受け取る
