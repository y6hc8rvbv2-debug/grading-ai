# ミライ予想：毎朝の自動作業（Claude 用の手順書）

毎朝この手順で、時事問題の **答え合わせ** と **新しい問題の追加** を行う。
対象ファイルは `yosou-game/questions.json` だけ。ほかのファイルは変更しない。

## 0. 準備
1. リポジトリ `y6hc8rvbv2-debug/grading-ai` で、ブランチ `claude/polymarket-prediction-platform-wwz93e` を最新にして作業する
   （`git fetch origin claude/polymarket-prediction-platform-wwz93e && git checkout claude/polymarket-prediction-platform-wwz93e && git pull`）
2. 今日の日付（日本時間）を確認する

## 1. 答え合わせ
`result` が `null` で、`resolveBy` の日時を過ぎている問題、または結果がすでに確定している問題について：
1. Web検索で結果を調べる。**公式発表**（主催者・政府・選挙管理委員会・日銀など）か、**大手報道2社以上**で確認できた場合だけ確定する
2. 問題の `criteria`（判定のルール）に厳密に当てはめて、`result` に `"yes"` か `"no"` を入れる
3. `sources` に根拠のページを1〜3件入れる（例：`{"title": "日本銀行 公表文", "url": "https://..."}`）。URLは実際に確認したものだけ
4. `note` に、結果を一言で書く（例：「政策金利を0.25%引き上げ、1.25%にすることが決まりました」）
5. 結果がはっきりしない・報道が食い違う場合は、確定しない（`null` のまま）。`resolveBy` から7日たっても判定できなければ `"void"`（中止）にして、`note` に理由を書く
6. ルールに当てはまらない事態（イベント中止、立候補なしなど）で `criteria` に「中止」と書かれている場合は `"void"`

## 2. 新しい問題の追加（毎日1〜2問）
- 受付中（締め切り前）の問題が **5〜12問** になるようにする
- 毎日必ず1問に `featured` へ今日の日付（例：`"2026-11-05"`）を入れる（「今日の1問」に表示される）。前の日の `featured` はそのままでよい
- 分野をばらけさせる：選挙・政治、経済、スポーツ、エンタメ、科学・テクノロジー、国際ニュースなど
- 必ず守ること：
  - **はい／いいえで答えられ、決まった日までに公式発表や大手報道で結果が確実に分かる問題だけ**にする
  - `criteria` には「何を見て、どうなったら『はい』か」を誰が読んでも同じ判断になるように書く。中止になる条件も書く
  - `deadline`（締め切り）は、結果が分かり始める前にする（例：選挙なら投票日の前日23:59、会合なら初日の前日23:59）
  - `resolveBy` は、結果が確実に報道される日時（余裕をもって）
  - 中立に書く。特定の政党・候補者・団体を応援したり、けなしたりする書き方をしない
  - **人の死・病気・事故・災害の被害・犯罪・個人の私生活を予想させる問題は出さない**
  - 一般の個人や未成年を対象にしない。お金を賭ける表現（「賭け」「オッズで儲ける」など）を使わない
  - 結果がすでにほぼ分かっている問題は出さない（開票中の選挙など）
- `ai` には、AIミライくんの予想を入れる。調べた情報をもとに、正直な見通しと理由を中学生にも分かる言葉で1〜2文で書く。`conf` は 1（ふつう）〜3（絶対）
- `id` は `n-年-短い英語名`（例：`n-2026-boj-dec`）。既存のIDと重ねない
- `createdAt` は追加した日時

## 3. 片付け
- 結果が出てから60日以上たった問題は削除してよい
- `updatedAt` を今の日時にする

## 4. 確認して保存
1. `python3 -c "import json; json.load(open('yosou-game/questions.json'))"` でJSONが正しいことを確認する
2. 日時はすべて `+09:00` 付きの形式（例：`2026-12-16T23:59:00+09:00`）になっているか確認する
3. コミットしてプッシュする（`git push -u origin claude/polymarket-prediction-platform-wwz93e`）。コミットメッセージは「ミライ予想：○月○日の問題更新（答え合わせ○問・新規○問）」
4. Artifact（https://claude.ai/artifact/7Aq4c7cJ7XDgomyFhJRYLW）も更新する：まず `action: "read"` でそのURLを読み、そのあと `yosou-game/index.html` を `url` 付きで publish し、`files` に `{"data.js": "yosou-game/data.js", "questions.json": "yosou-game/questions.json"}` を渡す。`capabilities` は指定しない（指定しないと、ランキング共有やAI機能の設定がそのまま引き継がれる）
5. 最後に、今日行ったこと（答え合わせした問題と結果、追加した問題）を短くまとめる
