# 市民の声（Voices of Citizens）— 国に、暮らしの声を。

国を選んで、政策に「生活の現状・気持ち・意見・政策提言」を届ける、政治に特化したSNS。
集まった声は自動で集計され、表とグラフで誰でも見られます。

- 画面：`voices/`（ビルド不要の静的ファイル）
- サーバー：`api/voices.js`（Vercel サーバーレス関数 1 本）
- データベース：PostgreSQL（表は初回アクセス時に自動作成）

## 本番モードにする（みんなの投稿を共有する）

データベースが未設定の間は「デモモード」（端末内だけに保存）で動きます。

1. Vercel の管理画面 → このプロジェクト → **Storage** → **Create Database** → **Neon（Postgres）** の無料プランを作成し、プロジェクトに接続する
   （環境変数 `DATABASE_URL` が自動で入ります）
2. 再デプロイする

任意の環境変数：

| 名前 | 役割 |
|---|---|
| `KG_ADMINS` | 通報を確認できる運営者のユーザーID（カンマ区切り） |
| `KG_SESSION_SECRET` | ログイン情報の署名鍵（未設定なら `DATABASE_URL` から自動生成） |

鍵や接続文字列はコードに書かず、必ず Vercel の環境変数に入れてください。
