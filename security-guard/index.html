守りダッシュボード

届いた電話・メール・SMSを自動で危険判定。不正ログイン・不正アクセスも、あなたの端末だけでチェック

💴 無料 🙅 登録・インストール不要 🗄️ データ保存なし
🔒
入力した内容はこの端末のブラウザの中だけで処理されます。サーバーには一切送信・保存されません（誰が使っても、他の利用者やあなたの入力は互いに見えません）。安心して貼り付けてください。

⚠️ このツールは「自分（や自分が管理する機器）を守る」ためのものです。他人のPC・サーバー・アカウントへの侵入や攻撃・反撃には使わないでください（個人が行うと不正アクセス禁止法などに触れます）。できるのは、異常の検知・あなた自身の設定強化・自分側でのブロックだけです。

📲 着信を自動チェック

電話・メール・SMS・SNSのメッセージが届いたら、この画面に届けるだけで自動判定し、「このメールは危険です」のようにすぐお知らせします。判定ボタンもURLのコピペも不要です。

📤 共有するだけ受信したSMS・メールを長押し →「共有」→「守りダッシュボード」。開いた瞬間に自動判定（Android／アプリとして追加したとき）
📋 コピーするだけ着信番号や本文をコピーしてこの画面に戻ると自動判定（下のスイッチをオン）
⚡ 受信と同時にスマホの自動化機能で「受信したらこの画面を開く」設定にすると、受信と同時に判定（設定方法は下へ）
⚡ 「受信と同時に自動判定」にする設定方法

ブラウザで動くアプリは、セキュリティ上の理由で電話やメールの受信を直接のぞくことができません。そのため、スマホの「共有」や「自動化」機能から内容を受け取る仕組みにしています。受け取った内容は端末の中だけで判定され、サーバーには送られません。

🤖 Androidの場合

  1. Chromeでこのページを開き、メニュー →「ホーム画面に追加」（または「アプリをインストール」）
  2. これで、SMS・メールアプリの「共有」先に守りダッシュボードが出ます。共有した瞬間に自動判定されます
  3. 完全に自動にしたい場合は、自動化アプリ（例：MacroDroid）で「SMS受信」や「着信」をきっかけに、次のURLを開くよう設定します
    SMS：https://grading-ai-security-guard.vercel.app/#kind=sms&text=【本文】
    電話：https://grading-ai-security-guard.vercel.app/#kind=call&text=【着信番号】

🍎 iPhoneの場合

  1. 「ショートカット」アプリ →「オートメーション」→「＋」→「メッセージ」（メールなら「メール」）
  2. 「メッセージに含まれる」に http などを入れ、「すぐに実行」を選ぶ
  3. アクションに「テキストをURLエンコード」（中身＝ショートカットの入力）→「URLを開く」を追加し、URLを
    https://grading-ai-security-guard.vercel.app/#kind=sms&text=＋エンコードしたテキスト にする
  4. iPhoneの電話の着信はAppleの制限で自動連携できません。着信履歴の番号をコピーしてこの画面を開けば自動判定されます

※ 機種・OSのバージョンによりメニュー名が少し違うことがあります。URLの「#」より後ろはサーバーに送られない部分なので、内容が外に出ることはありません。

🔑 不正ログイン検知

各サービスの「ログイン履歴」を貼り付けると、見慣れない場所・時刻・端末、連続失敗、不可能な移動などのあやしいサインを自動で採点します。
