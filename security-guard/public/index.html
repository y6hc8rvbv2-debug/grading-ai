守りダッシュボード

届いた電話・メール・SMSを自動で見張って危険をお知らせ。不正ログイン・不正アクセスも、あなたの端末だけでチェック

💴 無料 🙅 登録・インストール不要 🗄️ データ保存なし
🔒
不正ログイン・不正アクセスのチェックはこの端末のブラウザの中だけで処理され、サーバーには送信されません。自動チェックは、判定のためだけに届いた内容をサーバーへ送りますが、どこにも保存しません。

⚠️ このツールは「自分（や自分が管理する機器）を守る」ためのものです。他人のPC・サーバー・アカウントへの侵入や攻撃・反撃には使わないでください（個人が行うと不正アクセス禁止法などに触れます）。できるのは、異常の検知・あなた自身の設定強化・自分側でのブロックだけです。

🛡️ 届いたら自動でチェック

メール・SMS・電話が届くと、自動で中身をチェックして、危険なときだけ「このSMSは危険です」と通知と音声でお知らせします。無料・登録不要で、合言葉もいりません。最初に1回だけ、スマホの設定をしてください。

📩 ① 届くSMS・メール・電話（Androidは LINE などの通知も）
🔍 ② 自動でチェックスマホが内容を送り、詐欺のサインがないか調べる
🔔 ③ お知らせ危険・あやしいときだけ、通知と音声で知らせる

⚡ かんたん設定（タップするだけ）

🍎 iPhone：ショートカットを追加 🤖 Android：設定ファイルを読み込む

📮 設定で使う「送り先」（これ1つだけ）

https://grading-ai-security-guard.vercel.app/api/check

🍎 iPhone の設定（「ショートカット」アプリ・約3分）
  1. 「ショートカット」アプリ →「オートメーション」→「＋」→「メッセージ」（メールを見張るなら「メール」）
  2. 「メッセージに含まれる」に http と入れて（詐欺SMSのほとんどはリンク付きです）、「すぐに実行」を選ぶ
  3. 「URLの内容を取得」を追加 → URLに上の送り先を貼る → 詳細で 方法＝POST、本文を要求＝JSON、フィールド text ＝「ショートカットの入力」
  4. 「もし」を追加（「URLの内容」が「任意の値を持つ」）→ その中に「通知を表示」と「テキストを読み上げ」を入れ、中身を「URLの内容」にする

※ iPhoneの電話の着信とLINEなどのアプリは、Appleの制限で自動チェックできません。

🤖 Android の設定（無料アプリ「MacroDroid」・約3分）
  1. Google Play から「MacroDroid」を入れて、「マクロを追加」
  2. トリガーを選ぶ：「SMS受信」（すべて）、「着信」（すべて）、または「通知受信」（Gmail・LINE など）
  3. アクション「HTTPリクエスト」→ 方法＝POST、URL＝上の送り先、本文＝ SMSなら [sms_message]／電話なら [call_number]／通知なら [notification]。「応答を変数に保存」で変数（例：判定）に保存
  4. アクション「通知を表示」と「テキストを読み上げ」を追加し、中身を [lv=判定] に。制約「変数の値：判定 が 空ではない」を付ける

※ 機種やOSのバージョンで、メニューの名前が少し違うことがあります。
🔒 届いた内容はチェックのためだけに送られ、保存しません。危険なサインが見つからなければ何も通知しません。
